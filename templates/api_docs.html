Documentacion de la API

Endpoints REST para integrar el clasificador en otras aplicaciones

Base URL: http://localhost:8000/api
Formato: JSON | Autenticacion: No requerida para endpoints /api
GET /api
Estado general del sistema. Retorna si el modelo esta cargado y las clases disponibles.
Ver respuesta 
{
  "status": "ok",
  "modelo_cargado": true,
  "clases_disponibles": ["confeccion1", "confeccion2", "confeccion3"],
  "version": "3.0.0"
}
GET /api/clases
Lista todas las clases que el modelo puede predecir.
Ver respuesta 
{
  "clases": ["confeccion1", "confeccion2", "confeccion3"],
  "total": 3
}
POST /api/predecir
Clasifica una imagen con TTA. Acepta multipart/form-data con un campo file.
Ver ejemplo 
# Con curl:
curl -X POST http://localhost:8000/api/predecir \
  -F "file=@foto.jpg"

# Con Python:
import requests
r = requests.post("http://localhost:8000/api/predecir",
                  files={"file": open("foto.jpg", "rb")})
print(r.json())

# Respuesta:
{
  "confeccion": "confeccion1",
  "confianza": 92.34,
  "probabilidades": {
    "confeccion1": 92.34,
    "confeccion2": 5.12,
    "confeccion3": 2.54
  },
  "confiable": true,
  "tta": true
}
POST /api/predecir-lote
Clasifica multiples imagenes a la vez. Acepta multiples archivos en el campo files.
Ver ejemplo 
# Con curl:
curl -X POST http://localhost:8000/api/predecir-lote \
  -F "files=@foto1.jpg" \
  -F "files=@foto2.jpg"

# Respuesta:
{
  "resultados": [
    {"archivo": "foto1.jpg", "confeccion": "confeccion1", "confianza": 92.34, ...},
    {"archivo": "foto2.jpg", "confeccion": "confeccion3", "confianza": 87.12, ...}
  ],
  "total": 2
}
GET /api/modelo/status
Estado detallado del modelo (cargado, tamano, clases).
GET /api/dataset/stats
Estadisticas del dataset: numero de imagenes por clase.
GET /api/entrenamientos
Historial de los ultimos 20 entrenamientos.
GET /api/predicciones
Historial de las ultimas 50 predicciones.

API Escaner QR

GET /api/qr/camaras
Lista camaras disponibles para escaneo QR.
Ver respuesta 
{
  "cameras": [{"id": "usb_0", "type": "usb", "name": "Camara USB 0", "resolution": "640x480"}],
  "total": 1
}
POST /api/qr/escanear
Escanea un frame de la camara en busca de codigos QR y barras. Requiere param camera_id.
Ver ejemplo 
curl -X POST "http://localhost:8000/api/qr/escanear?camera_id=usb_0"
{
  "resultados": [{"type": "QR", "data": "https://example.com"}],
  "total": 1
}
POST /api/qr/escanear-imagen
Escanea una imagen subida en busca de codigos QR y barras. Campo: file.
Ver ejemplo 
curl -X POST http://localhost:8000/api/qr/escanear-imagen -F "file=@foto_con_qr.jpg"
GET /api/qr/historial
Historial de los ultimos 50 escaneos QR/barcode.

API Disparador / Sensor

POST /api/disparar
Endpoint para sensores externos. Captura foto de la camara por defecto, ejecuta clasificacion ML + deteccion QR. Sin autenticacion. Configure la camara y retorno en Ajustes.
Ver respuesta (sin retorno) 
{
  "timestamp": "2026-05-06T23:30:00",
  "camera": "usb_0",
  "ml": {
    "confeccion": "confeccion2",
    "confianza": 89.86,
    "probabilidades": {"confeccion2": 89.86, "confeccion3": 7.21, "confeccion1": 2.93},
    "confiable": true
  },
  "qr": [{"type": "QR", "data": "https://example.com"}],
  "qr_count": 1,
  "capture_path": "/path/to/trigger_captures/trigger_20260506_233000.jpg"
}
Ver respuesta (con retorno activo) 
{
  "status": "processing",
  "callback": true,
  "callback_url": "https://tu-servidor.com/webhook",
  "timestamp": "2026-05-06T23:30:00"
}
// El resultado completo se envia via POST al callback_url
