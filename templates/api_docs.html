Documentacion de la API

Endpoints REST para integrar el clasificador en otras aplicaciones

Base URL: http://localhost:8000/api
Formato: JSON | Auth: No requerida para endpoints /api
GET /api
Estado general del sistema. Retorna si el modelo esta cargado y las clases disponibles.
Ver respuesta 
{
  "status": "ok",
  "modelo_cargado": true,
  "clases_disponibles": ["confeccion1", "confeccion2", "confeccion3"],
  "version": "3.0.0"
}
GET /api/clases
Lista todas las clases que el modelo puede predecir.
Ver respuesta 
{
  "clases": ["confeccion1", "confeccion2", "confeccion3"],
  "total": 3
}
POST /api/predecir
Clasifica una imagen con TTA. Acepta multipart/form-data con un campo file.
Ver ejemplo 
# Con curl:
curl -X POST http://localhost:8000/api/predecir \
  -F "file=@foto.jpg"

# Con Python:
import requests
r = requests.post("http://localhost:8000/api/predecir",
                  files={"file": open("foto.jpg", "rb")})
print(r.json())

# Respuesta:
{
  "confeccion": "confeccion1",
  "confianza": 92.34,
  "probabilidades": {
    "confeccion1": 92.34,
    "confeccion2": 5.12,
    "confeccion3": 2.54
  },
  "confiable": true,
  "tta": true
}
POST /api/predecir-lote
Clasifica multiples imagenes a la vez. Acepta multiples archivos en el campo files.
Ver ejemplo 
# Con curl:
curl -X POST http://localhost:8000/api/predecir-lote \
  -F "files=@foto1.jpg" \
  -F "files=@foto2.jpg"

# Respuesta:
{
  "resultados": [
    {"archivo": "foto1.jpg", "confeccion": "confeccion1", "confianza": 92.34, ...},
    {"archivo": "foto2.jpg", "confeccion": "confeccion3", "confianza": 87.12, ...}
  ],
  "total": 2
}
GET /api/modelo/status
Estado detallado del modelo (cargado, tamano, clases).
GET /api/dataset/stats
Estadisticas del dataset: numero de imagenes por clase.
GET /api/entrenamientos
Historial de los ultimos 20 entrenamientos.
GET /api/predicciones
Historial de las ultimas 50 predicciones.
