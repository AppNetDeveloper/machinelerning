Inicio Rapido

  • Usuario: admin
  • Password: 123456789
Cambia el password por defecto en Configuracion
2. Flujo basico
1. Subir fotos 2. Entrenar modelo 3. Predecir
Gestion del Dataset
Crear clases

Ve a Dataset y crea una clase por cada tipo de confeccion:

  1. Escribe el nombre de la clase (ej: manzana)
  2. Clic en "Crear Clase"
  3. Repite para cada tipo
Subir imagenes

Selecciona una clase y sube fotos:

  • Minimo: 100 fotos por clase
  • Recomendado: 300-500 fotos por clase
  • Formatos: JPG, PNG, BMP, WebP
Consejos para buenas fotos
  • Varia el angulo de la camara
  • Incluye diferentes iluminaciones
  • Muestra la caja completa y parcial
  • Incluye casos dificiles (danadas, parciales)
  • Fondo variado (no siempre el mismo)
Augmentacion automatica

Si tienes menos de 300 fotos por clase, puedes usar el boton "Augmentar Dataset" en Entrenamiento para generar variaciones automaticas.

Camaras
Tipos de camara
Camaras USB
  1. Conecta la camara USB al servidor
  2. Ve a Camaras
  3. Clic en "Escanear camaras USB"
  4. Selecciona la camara encontrada
Camaras IP
  1. Ve a Camaras
  2. En "Anadir Camara IP" completa:
    • Nombre: Identificador descriptivo
    • Protocolo: RTSP, HTTP o HTTPS
    • IP: Direccion de la camara
    • Puerto: 554 (RTSP) o 80 (HTTP)
    • Ruta: /stream1 o similar
  3. Clic en "Registrar Camara IP"
Capturar fotos con camara
  1. Selecciona una camara (icono ojo)
  2. Espera que cargue la vista previa
  3. Selecciona la clase destino
  4. Clic en "CAPTURAR AHORA"
Editar camaras

Clic en el icono para modificar nombre, URL o callback.

Entrenamiento
Preparar el entrenamiento
  1. Ve a Entrenamiento
  2. Revisa las estadisticas del dataset
  3. Si alguna clase tiene menos de 300 fotos, usa "Augmentar Dataset"
Iniciar entrenamiento
  1. Clic en "Iniciar Entrenamiento"
  2. Observa el progreso en tiempo real
  3. El proceso tiene 2 fases:
    • Fase 1: Entrena solo la capa clasificadora (10 epocas)
    • Fase 2: Fine-tuning de capas altas (50 epocas)
Indicadores importantes
Train LossDebe disminuir gradualmente
Val LossDebe disminuir sin alejarse mucho del Train
Val AccPorcentaje de acierto en validacion
LRLearning rate (se ajusta automaticamente)
Tiempo estimado: 5-30 minutos dependiendo del dataset y hardware.
Predicciones
Predecir una imagen
  1. Ve a Predicciones
  2. Sube una imagen o arrastrala al area
  3. Clic en "Predecir"
  4. Revisa el resultado:
    • Clase predicha: Tipo de confeccion detectado
    • Confianza: Porcentaje de certeza (mayor a 80% es bueno)
    • Barra verde: Resultado confiable
    • Barra roja: Resultado incierto
Interpretar resultados
  • Confianza > 90%: Muy confiable
  • Confianza 70-90%: Confiable
  • Confianza < 70%: Poco confiable, verificar manualmente
Escaner QR / Codigos de Barras
Escanear codigos
  1. Ve a QR Escaner
  2. Selecciona una camara
  3. Clic en "Escanear QR"
  4. Los resultados aparecen en pantalla
Codigos soportados
  • QR Code: Codigos QR 2D
  • EAN-13/UPC: Codigos de barras de productos
  • Code 128/39: Codigos alfanumericos
Historial

Todos los escaneos se guardan automaticamente en el historial.

Integracion MQTT / IoT
Configurar MQTT
  1. Ve a MQTT
  2. Ingresa los datos del broker:
    • Host: Direccion del broker (ej: mqtt://192.168.1.100)
    • Puerto: 1883 (default)
    • Usuario/Password: Credenciales del broker
  3. Clic en "Conectar"
Configurar triggers
  1. Ve a Camaras
  2. Edita una camara (icono lapiz)
  3. Configura la URL de callback
  4. Activa el callback
Flujo IoT
Sensor fisico → POST /api/disparar/[slug] → Captura → ML + QR → MQTT/Webhook
Solucion de Problemas
Entrenamiento
"Val Acc muy bajo (< 50%)"
  • Necesitas mas fotos (minimo 300 por clase)
  • Las clases deben ser visualmente distintas
  • Usa "Augmentar Dataset" si tienes pocas fotos
"CUDA out of memory"
  • Reduce BATCH_SIZE en config.py
  • Cierra otras aplicaciones que usen GPU
"Error DNNL bf16"
  • Ya esta corregido automaticamente
  • Si persiste, reinicia el servidor
Camaras
"Camara no detectada"
  • Verifica conexion USB
  • Prueba con otro indice (0, 1, 2...)
  • Verifica permisos: sudo usermod -aG video $USER
"Camara IP no conecta"
  • Verifica la IP: ping 192.168.1.100
  • Prueba la URL RTSP en VLC
  • Verifica usuario y password
Errores comunes
"FileNotFoundError"
  • Dataset corrupto - re-entrenar desde cero
  • Eliminar checkpoint: rm checkpoint.pth
"Puerto en uso"
  • lsof -i :8000 para ver procesos
  • kill -9 [PID] para matar proceso
