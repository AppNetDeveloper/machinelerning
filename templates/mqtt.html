Como funciona

1. Configura el broker MQTT arriba.
2. Agrega triggers: mapea un topico a una camara.
3. Define variables a extraer del payload (ej: barcode,sensor_id).
4. Cuando llegue un mensaje, se activa la camara y se procesa con ML.
5. El resultado (variables del sensor + ML) se publica en el topico de resultado.
6. El topico resultado soporta templates: resultado/{barcode}

Ejemplo payload JSON:
{"barcode": "ABC123", "linea": "1", "sensor_id": "S01"}

Variables a extraer: barcode,linea,sensor_id

Resultado publicado:
{"source": {"topic": "...", "variables": {"barcode": "ABC123", ...}}, "ml": {...}}
